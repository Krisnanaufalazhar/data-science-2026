## Ringkasan Materi Pertemuan 9–13

### Pertemuan 9 — Algoritma Klasifikasi

Mempelajari algoritma klasifikasi menggunakan **Logistic Regression** dan **Decision Tree**. Evaluasi model dilakukan menggunakan **Confusion Matrix, Accuracy, Precision, Recall, dan F1-Score** untuk mengetahui performa model dalam melakukan klasifikasi.

### Pertemuan 10 — Ensemble Learning & Imbalanced Dataset

Mempelajari metode **Random Forest** sebagai salah satu teknik Ensemble Learning serta permasalahan **Imbalanced Dataset**. Praktikum juga mencakup **Customer Churn Prediction** dan analisis metrik evaluasi untuk memahami mengapa Accuracy saja tidak cukup ketika distribusi kelas tidak seimbang.

### Pertemuan 11 — Unsupervised Learning

Mempelajari teknik **Clustering** menggunakan K-Means dan Hierarchical Clustering. Metode **Elbow** digunakan untuk membantu menentukan jumlah cluster yang optimal sebelum melakukan proses clustering.

### Pertemuan 12 — Asosiasi Data & Sistem Rekomendasi

Mempelajari **Algoritma Apriori** untuk Market Basket Analysis serta konsep dasar sistem rekomendasi menggunakan **Collaborative Filtering** dan **Content-Based Filtering**.

### Pertemuan 13 — Deep Learning & NLP

Mempelajari konsep dasar **Artificial Neural Network** melalui klasifikasi data non-linear menggunakan dataset `make_moons`. Selain itu, dipelajari pengolahan teks menggunakan **TF-IDF** dan klasifikasi sentimen ulasan produk menggunakan **Logistic Regression**.

## Cara Menjalankan Notebook

### Google Colab

1. Buka notebook yang ingin dijalankan.
2. Download atau buka file `.ipynb` menggunakan Google Colab.
3. Jalankan seluruh sel dari atas ke bawah.
4. Pastikan seluruh kode dapat dijalankan tanpa error.

### Jupyter Notebook

Install library yang diperlukan:

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn tensorflow mlxtend
```

Kemudian jalankan:

```bash
jupyter notebook
```

Buka notebook yang ingin dijalankan dan jalankan seluruh sel secara berurutan.

## Kesimpulan

Pembelajaran Pengantar Data Science dari Pertemuan 1 hingga Pertemuan 13 memberikan pengalaman dalam memahami proses Data Science secara bertahap, mulai dari pengolahan data hingga penerapan berbagai metode Machine Learning dan Deep Learning.

Pada tahap awal, pembelajaran dimulai dengan pengenalan Data Science, pemrograman Python, penggunaan NumPy dan Pandas, data cleaning, statistika, visualisasi data, serta persiapan data. Selanjutnya, pembelajaran berkembang ke Machine Learning melalui regresi dan berbagai algoritma klasifikasi.

Pada Pertemuan 9 dan 10, dipelajari klasifikasi menggunakan Logistic Regression, Decision Tree, Random Forest, evaluasi model, serta penanganan dataset yang tidak seimbang. Pada Pertemuan 11, pembelajaran berlanjut ke Unsupervised Learning menggunakan K-Means dan Hierarchical Clustering. Pertemuan 12 memperkenalkan Association Rule Mining menggunakan Apriori serta konsep dasar sistem rekomendasi.

Pada Pertemuan 13, pembelajaran berkembang ke Deep Learning dan NLP melalui Neural Network untuk klasifikasi data non-linear serta TF-IDF dan Logistic Regression untuk analisis sentimen.

Secara keseluruhan, rangkaian praktikum ini memberikan pemahaman bahwa Data Science tidak hanya berkaitan dengan pembuatan model, tetapi juga mencakup proses memahami data, melakukan preprocessing, memilih metode yang sesuai, mengevaluasi hasil, serta menginterpretasikan temuan.

Repository ini menjadi dokumentasi perjalanan pembelajaran sekaligus portofolio yang menunjukkan perkembangan kemampuan dalam menerapkan konsep Data Science dari tahap dasar hingga Machine Learning, Deep Learning, dan NLP.
