## Cara Menjalankan Notebook

### Menggunakan Google Colab

1. Buka notebook yang diinginkan.
2. Pilih **Open in Colab** atau upload file `.ipynb` ke Google Colab.
3. Jalankan sel secara berurutan dari atas ke bawah.

### Menggunakan Jupyter Notebook

1. Install Python.
2. Install library yang dibutuhkan:

   ```bash
   pip install pandas numpy matplotlib seaborn scipy scikit-learn
   ```
3. Jalankan Jupyter Notebook:

   ```bash
   jupyter notebook
   ```
4. Buka file notebook yang diinginkan dan jalankan seluruh sel.
